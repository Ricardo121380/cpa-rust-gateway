## 本轮视觉变化

| 部分 | V4 设计 |
|---|---|
| 全局层级 | 银灰环境 → 浅灰工作画布 → 白色数据面板；深色采用石墨灰的三个明度层。数据区始终实底。 |
| 导航与标题 | 顶栏显示“导航组 / 当前栏目”；移除每页重复的 PRISM WORKSPACE。标题 28px，说明与作用域紧邻标题，主操作对齐右侧。 |
| 概览数字 | 四项指标组合成一个实底面板，内部细线分隔；数字 28px、元数据 12px，不使用四张玻璃卡片。 |
| 列表结构 | 账号池与模型目录将筛选、表格和结果数量组合成一个数据面板。桌面行高约 66–68px；移动账号改为卡片，筛选输入和状态下拉同排。 |
| 颜色分工 | Apple 蓝用于操作、焦点和选中；正常状态改为绿色圆点与中性文字；警告和错误保留文字标签与低饱和背景。 |
| 详情层级 | 账号、目录 target、请求尝试、价格条目、上游、模型、路由、访问组、Key、出口策略等对象详情使用右侧检查面板。编辑表单、确认与校验仍居中。 |
| 玻璃 | 顶栏、侧栏、草稿坞保留折射、tint、高光边环、内阴影与版本材质。收敛环境光和外阴影，最多三面 chrome 玻璃；检查面板不叠加另一层玻璃。 |

账号详情继续采用“运行状态 / 权益证据 / 配置与失败”三个分页。桌面检查面板宽 520px，从顶栏下方开始；390px 手机宽度下左右各留 12px、面板宽 366px，支持内部滚动。原生 dialog 的 Escape、焦点恢复和模态语义保留。

## 拟议 token 调整

这些变化只在独立原型中生效；正式实施时将角色合并到既有 token，不直接复制整份内联样式，不改透镜数学来补偿配色。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 环境底色 `--canvas` | `#eceef2` | `#101217` |
| 工作画布 `--content-canvas` | `#f5f5f7` | `#191b20` |
| 面板 `--surface` | `#ffffff` | `#222429` |
| 控件/辅助底色 `--surface-2` | `#f2f3f5` | `#2b2e34` |
| 主文字 `--ink` | `#1d1d1f` | `#f5f5f7` |
| 次文字 `--ink-2` | `#63656b` | `#a6a9b1` |
| 分隔线 `--separator` | `#dfe1e5` | `#383b43` |
| 链接与焦点 `--tint` | `#0066cc` | `#69b0ff` |
| 白字按钮 `--tint-fill` | `#0071e3` | `#0f6fd6` |

浅色环境光强度从 `.42/.38/.34/.26` 收敛为 `.20/.12/.12/.08`，深色为 `.20/.12/.14/.07`；grain 从 `.40/.45` 收敛为 `.18`。环境光用低饱和蓝灰、青灰和微弱暖灰，光谱边缘保留。外阴影仍有四层，降低强度；受光边环、内阴影和 SVG displacement 未改。

形状分工：数据面板 14px、常规控件 9–10px、主操作与草稿坞胶囊、桌面检查面板 18px。避免将每个控件都做成同样的胶囊。

主题覆盖使用 `:root[data-theme]`，与既有 token 的选择器权重一致；增强对比度覆盖必须置于其后，不能被新主题变量压住。

## 本轮验证

- 在 OpenDesign 原生应用打开 V4，并实测总览 → 账号池；保留内嵌预览注入 base URL 时的 hash 导航修正。
- 1440×900 和 390×844 分别逐项点击全部 14 个栏目，标题、页面内容和导航正常，页面画布无横向溢出。长表可以在自身容器内滚动。
- 1280×720 下全部 14 个导航入口可见；浅色账号池、总览、手机账号卡、手机详情与深色桌面经过视觉检查。
- 同为 1440×900，账号池首行位置从 V3 的 541.30px 提前至 464.58px，减少 76.72px；六行示例账号可完整显示。该数值仅用于固定视口比较。
- 平台筛选得到两条 Grok 账号；关键词过滤空态和清除筛选恢复正常。未观测权益保留 null 语义。Escape 关闭详情后焦点返回来源按钮。
- 桌面对象详情在右侧；草稿校验保持 600px 居中对话框。草稿显示三面玻璃，活动版本恢复两面。原型未发送真实操作。
- 减少透明度和增强对比度的计算滤镜为 `none`；高对比度主次文字一致；减少动态效果为 `0ms`。正常模式仍计算为 SVG lens filter。
- 检查了浅色文字/实底的代表对比度：正常状态文字约 5.8:1、警告约 4.8:1、主操作白字约 4.7:1；深色次文字/面板约 6.6:1。它们不代表所有动态玻璃背景都完成逐像素评测。
- `node --check` 通过，预览未捕获 error/warn；MCP 读回与仓库副本一致，V3 未覆盖。

本次是设计原型细化，没有执行生产全量测试、真实 API/Provider 验证或部署。辅助媒体查询和跨浏览器回退沿用 V3，正式实施仍须执行开发方案 F0–F4 的验收。
