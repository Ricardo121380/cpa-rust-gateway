# Prism 紧凑工作台设计规范

本轮采用已安装frontend-design、ui-ux-pro-max与React best practices。用户确认Apple Liquid Glass，拒绝泛用模板。

- 材质与颜色：银白#F5F5F7、内容白#FFFFFF、石墨#1D1D1F、次级#636366、Apple蓝#007AFF、深色底#16181D；映射到现有语义token，实际前景组合须通过对比度检查。
- 字体：系统UI/PingFang，正文14–16px，标题22–24px，辅助13px，等宽仅用于模型ID/必要数值。取消巨大标题、重复眉题与卡片装饰。
- 结构：固定玻璃导航；内容为同色系低强度层次。页面标题/主操作 → 筛选 → 表格或分栏 → 分页。提供商采用列表+工作区而非巨大卡片。
- 密度：4/8间距体系，桌面行约56–68px，内容内边距20–24px，面板16px圆角、控件10px；状态不只用颜色。
- 详情520px；390px手机左右12px。手机表格转换统一对象卡片，主要操作不依赖横向滚动或hover。
- 交互：明确主动作、共享批量栏、字段错误、未保存保护、固定表单操作区；成功后服务端重读；409不重放。轻动效仅解释操作，遵从辅助偏好。
- React：复用TanStack Query；独立读取并行，重复关系查找建Map，搜索节流；不为优化加入新依赖、跨listener请求或额外chunk。

已审查UI Pro Max的Liquid Glass样式条目、批量操作/响应式表格及React筛选建议。初次自动设计系统返回营销Hero模板，与管理工具不符，未采用。
