## 这版如何操作

| 任务 | 入口与结果 |
| --- | --- |
| 添加 Kimi API 等配置 | 侧栏“API 配置” → “添加 API 配置”；一张表单填写必要信息，保存后回到列表，无需预建服务 / 接口。 |
| 授权登录 | 侧栏“授权登录”选择渠道；外部授权由明确标注的模拟器替代，成功后直接登记账号，可“查看账号”，不再第二次保存。 |
| 导入认证文件 | “账号管理” → “导入认证文件”；载入示例 JSON，逐项显示保存结果，失败项单独修正和重试。 |
| 设置模型权限 | 从账号 / API 配置行的“模型”进入。已有模型权限保留，新模型默认不开放；权限选择不阻塞接入。 |
| 日常管理 | 列表行直接显示主要状态和原因，提供模型、详情、启停、更多操作；异常账号显示相应处理入口。 |
| 观察例外 | 页面底部折叠的“原型演示工具”切换合成数据或注入故障；再通过正常页面操作，演示工具不是产品功能。 |

取消了第一版的三步向导和右侧逐步演练按钮。原型现在从正常账号列表开始，桌面显示表格，窄屏显示账号卡片。

## 参考来源与保留约束

视觉继续复用既有 [ChatGPT / C2C Liquid V2](chatgpt-prism-liquid-v2/CPAR-Prism-Liquid-v2.html) 的页内工作区，以及 [Kimi K3 Liquid Glass V6](prism-liquid-glass-v6.html) 的完整原始样式、Prism 标识、顶栏、侧栏和深浅主题。原始文件未改动，基础代码版本为 `9fc4ceb4e12aab9c60658869706828a7d5d8312f`。

操作链路按冻结版本的 CPA 管理 UI 和 CPAMP 源码核对，详见[逐项对照与证据](prism-account-flows.reference.md)。本轮没有运行上游管理 UI，不宣称与某个线上部署完全一致。已有的配置并发、权限、状态和历史保留约定继续约束原型。

- 已有待应用修改：列明旧修改和本次保存，核对后一起应用或保留待应用；清单发生并发变化时重新读取。
- 授权结果不明：先查询；给原账号重新授权时，身份不同不能覆盖原账号。新增账号可接受另一可靠身份，同一身份不重复创建。
- 更新授权：保留模型权限、连接和停用意图；停用账号不被自动启用。
- 停用与删除：停用停止新分配，在途自然结束；删除预览后一次确认，保留共享连接、其他账号和历史，不冒称撤销上游授权。
- 保存、生效、模型目录、权限及调用证据分别反馈。未提供额度不视为零余额；解除隔离不视为已验证恢复。
