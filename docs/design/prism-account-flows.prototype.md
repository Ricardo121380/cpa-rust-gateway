## 如何走查

优先体验 **01 Kimi 首次接入、03 授权中断、05 日常诊断**。右侧引导按钮会执行当前步骤；左侧为实际操作区。需要观察边界时，展开“自由演练”。演练开关和引导区仅服务本次讨论，不是未来产品按钮。

| 场景 | 观察重点 |
| --- | --- |
| 01 Kimi 首次接入 | 只提供必要信息；自动准备连接，新模型就地选开放范围，保存后自动生效 |
| 02 OAuth 正常 | 授权后回到同一任务；授权保存与配置生效分开反馈 |
| 03 授权中断 | 回调丢失先核对，不重复创建，不把停止等待说成撤销授权 |
| 04 连接与待应用 | 多个匹配时就地选连接；旧修改和新接入一起核对；并发变化后重读清单 |
| 05 日常诊断 | 区分陈旧目录、额度未提供、读取失败和明确授权失效；更新授权保留权限 |
| 06 停用与删除 | 停用后在途自然结束；删除先预览，共享连接、其他账号和历史保留 |
| 07 重复授权 | 相同身份更新原账号；保留停用意图、连接及权限；不同或未知身份先核对 |
| 08 应用与隔离 | 保存成功但应用失败的全局提示；解除本地隔离仍显示尚未验证 |

请反馈：哪一步仍然绕、哪条状态看不懂，以及是否能直接找到下一步操作。即使引导按钮都能完成，仍可以否定或调整流程。

## 本地走查与边界

EgoLite 的八个引导场景均完成。额外检查了空开放范围阻止保存、更新授权保留已有权限、身份冲突/未知时中断再核对、接入中停用不能跳过模型开放选择，以及额度读取失败保留此前耗尽限制。

走查修正了两类容易误导的反馈：填写新 API Key 尚未保存时仍保留旧授权失效状态；已有模型在更新授权时直接显示保留的权限，不再要求重新选择。

脚本语法检查通过；单文件没有外部资源引用或网络调用，CSP 禁止连接外部服务。没有增加测试套件。浏览器检查只覆盖本地原型，不构成生产前端、三协议兼容或真实渠道验收。

- 用户反馈：PENDING，尚未确认操作模型。
- 真实账号、推理调用、生产修改与部署：NOT_RUN。
- 模型名称、额度、身份、在途请求与历史均为合成数据；模型发现与调用结果明确标注为模拟。
- 仅账号流程可操作；导航中的其他模块保留视觉位置，不模拟全产品功能。
- 本原型是独立讨论资产，不合入生产实现；后续实施需依据最终确认的约定重新接入真实服务并验证。
