# Prism 网关控制台 · v7 工作台方向 — 实现规格

> 面向生产迁移（React / Vite / TanStack Query / Zustand，同源 API，严格 CSP，四个静态文件）。
> 本规格只描述**可迁移的组件规则与交互契约**，原型实现见 `index.html`（单文件、零外部依赖、全合成数据）。

## 1. 视觉令牌（CSS 自定义属性，oklch）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--canvas` | `oklch(0.945 0.008 250)` | `oklch(0.175 0.012 264)` | 页面底色（银白 / 石墨） |
| `--tint` | `oklch(0.978 0.005 250 / .84)` | `oklch(0.24 0.014 264 / .84)` | 内容面统一着色底层 |
| `--surface` / `--surface-2` | `0.988` / `0.952` | `0.25` / `0.30` | 控件与次级填充 |
| `--fg` / `--fg-2` / `--muted` | `0.25` / `0.43` / `0.52` | `0.93` / `0.79` / `0.68` | 三级文字 |
| `--border` / `--border-strong` | `0.855` / `0.76` | 白色 10% / 20% | 深色主题用半透明白边 |
| `--accent` | `oklch(0.515 0.175 256)` | `oklch(0.72 0.13 250)` | Apple 蓝深阶；浅色下白字对比 ≈5.6:1 |
| `--accent-fg` | `oklch(0.985 …)` | `oklch(0.17 …)` | 主按钮文字，随主题反转 |
| `--success` / `--warn` / `--danger` | 语义色，仅用于状态点与回执 | 同左 | 不做装饰 |

规则：每屏 accent 可见使用 ≤ 2（一个主按钮 + 一个激活导航）；hover 只动背景 L 通道 ±0.06–0.12，前景不变暗；禁用是唯一允许降低对比的状态。

## 2. 字体与排版

- 单一系统栈：`-apple-system, "SF Pro Text", "PingFang SC", "Segoe UI", "Microsoft YaHei", sans-serif`；等宽：`ui-monospace, "SF Mono", Menlo`（邮箱、主机、密钥、模型 ID）。
- 数据密集型工具允许单字族；层级靠字重三档：400 读 / 510 界面 / 590 标题与按钮。
- 字级：h1 23 / h2 16 / 正文 13.5–14 / 辅助 11.5–12.5。CJK 行高：标题 1.35–1.4，正文 1.6–1.7；CJK 不用负字距；全大写拉丁标签 ≥0.06em。

## 3. 材质系统（至多三层玻璃铬件）

1. **顶栏**（56px）、2. **侧栏**（236px，移动端为底部横滚导航）、3. **右侧检查器**（392px 抽屉）——这三者用 `.glass`（`backdrop-filter: saturate(1.7) blur(22px)` + 半透明底）。
- 内容区**不**再叠加玻璃：用统一的 `--tint` 着色面 + 1px `--border` + 轻投影，保证数据可读。
- `data-transparency="reduced"`：玻璃退化为不透明 `--surface`，关闭 backdrop-filter 与底层着色光晕。
- `data-motion="reduced"`：骨架屏不动画，过渡 ≤0.01ms。
- 偏好**仅存内存**（Zustand 非持久化 slice），不写 localStorage。

## 4. 布局与响应式

- 壳层：CSS Grid `56px / 236px + 1fr`；内容栏 max-width 1080px，桌面 padding 32px，**移动端（≤860px）12px inset**，页面不横向滚动（表格用 `overflow-x:auto` 容器自吞）。
- 目标断点：1440×900、1280×720、390×844。移动端侧栏 → 底部固定横滚导航（含 safe-area inset）。
- 所有可点控件 min-height 44px（按钮、输入、导航项、单选行）；表格行高 48px。

## 5. 页面结构契约（可迁移的信息架构）

八个日常工作区：仪表盘 / 账号管理 / AI 提供商 / 模型管理 / API 密钥 / 请求与日志 / 用量与价格 / 设置。三个完整页的规则可推广到其余页面：

- **页头**：眉题（11px 大写感）+ h1 + 一句用途说明 + 右侧唯一主操作。无营销区、无大卡片阵。
- **账号管理**：按渠道分组（API 直连 / Codex·ChatGPT / Claude / Kimi / Kiro / Grok·Web·Console·Build）。授权 modal **渠道优先**：第一步选渠道（协议芯片由渠道自动决定），第二步邮箱；**不出现提供商/端点字段**。授权属原生运行时操作 → 立即生效并出「已保存」回执。
- **AI 提供商**：紧凑清单（提供商 / 协议 / 主机 / 账号数 / 状态）。行点击 → **右侧只读检查器**；「编辑连接」为简单居中 modal，提交后**进入待应用批次**而非直接生效。
- **用量与价格**：价格目录**行内编辑**（点击单元格 → 数字输入，Enter 提交 / Esc 取消 / 非法值回滚并提示）；保存前弹**完整变更预览**（旧值 → 新值 diff）；分页器每页 50 条；未定价单元格诚实显示「— 未定价」。**路由价格策略是同页内联草稿**，与目录作用域独立，保存目录绝不携带策略。

## 6. 编辑器形态分配（硬规则）

| 形态 | 用于 |
|---|---|
| 居中简单 modal | 单实体、≤4 字段的表单（授权、新建密钥、编辑连接） |
| 右侧抽屉 | 只读详情（提供商检查器） |
| 页内联编辑 | 多步 / 多实体编辑器（价格目录、策略草稿、批次复核） |

所有 modal 结构固定：头部（标题 + 关闭）/ 内容 / 操作底栏（**至多一个主按钮** + 一个取消）。支持焦点圈定、Esc、关闭后焦点归还触发元素。

## 7. 待应用批次与回执语义（核心交互契约）

- 高级配置修改（提供商连接、路由价格策略草稿）**统一进入单个待应用批次**；顶栏胶囊实时显示计数。
- 批次复核为内联清单：人类可读摘要（谁、改了什么、改成什么）+ 主按钮「**校验并应用**」。
- 校验规则示例：策略倍率必须在 0.5–5.0。失败项**保留在批次中**，成功项生效 → 「部分完成」回执。
- 应用进行中按 Esc 取消 → 「**结果未知**」回执：明确告知写入状态无法确认、**系统不会自动重放**、批次保持不变。
- 原生运行时操作（账号授权、新建密钥）**不进入批次**，立即生效。
- 回执四态必须可区分：`已全局保存`（success）/ `草稿待应用`（accent）/ `部分完成`（warn）/ `结果未知`（danger），均带时间戳与「演示环境」标注。回执不用左侧色条卡片样式。

## 8. 状态覆盖清单（每页必须可演示）

输入错误（授权邮箱格式、价格非法值）、加载（页面切换骨架 ~300ms）、空态（筛选无结果 + 清除按钮）、成功（回执）、禁用（无修改时的保存/提交、单页分页器）、未保存丢弃确认（脏 modal 关闭前的内联确认条）、键盘（Tab 圈定 / Esc 分层：单元格 → modal → 检查器 / Enter 激活行）。

## 9. 诚实性约束

不出现聚合成功率、定价置信度等推断指标；只有计数口径的累计值。无后端内部概念（revision、hash、内部 ID）进入日常流。全部数据标注为合成样例。

## 10. 工程落地（React 迁移映射）

- 原型零依赖、单文件，等价于生产约束（严格 CSP、无外部字体/图片/运行时依赖）：直接映射为 design-token CSS 文件 + 组件模块，无需新增 chunk。
- 状态：主题/透明度/动效 = 内存 Zustand slice；数据 = TanStack Query（原型中的 render 即 query 成功态，骨架即 pending 态）；批次 = 单一 store，「校验并应用」= 一次批量 mutation，按项收集 settled 结果映射到四类回执。
- 图标：内联 monoline SVG（1.7px stroke, currentColor），无图标库。
