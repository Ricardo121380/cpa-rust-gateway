# 账号接入与模型来源连续性 — 2026-09-21

本批落实 G01 与 G03；不是全站视觉或功能对齐完成。没有生产变更、真实渠道授权或真实推理。

## 实现

- 支持官方授权的渠道默认展示登录说明及唯一“授权登录”主操作。支持导入时提供次级方式切换；切换清除临时凭据、文件材料和旧错误。
- 仅导入渠道直接显示导入表单，不显示不可用的OAuth入口。渠道切换重新按能力决定默认方式。
- 保留原渠道专用会话、取消、未确认结果和导入回执，不修改鉴权契约。
- 提供商“开放模型”进入携带 upstream_id 的目录；不猜测接口、账号或权限。
- G02复核：AppShell早已有模型工作区双入口，上轮审计漏看外壳。已更正文档；跨入口筛选连续性仍待后续完善。
