# V2 用量与费用结构补齐

2026-09-22，基于 `7183bc1` 继续实现用户的 V2 原稿。本批仅本地实施，不发布生产。

## 实现

- 用量页采用原稿的四指标、费用来源与费用完整性双栏；六类 Token 及各自置信度作为下方独立明细保留。分组维度移至 Token 明细，避免干扰模型费用分组。
- 请求数、成功率、P95 来自 `summarizeRequests`；费用来自 `listOperationalBilling`。二者使用相同时间范围、各自服务端快照，不以 usage 行数替代外部请求数。
- 费用按原始模型 ID 聚合，保留大小写和多个来源。每页 100 条，按服务端 cursor 加载更多；未到末页明确标记模型金额未完整加载。右侧使用服务端完整范围 summary，不拿已加载记录冒充总数。
- 空账本/未知金额显示未知，已观测零保留零；不添加未知币种。精确计价占比取真实 summary。
- 账本不支持密钥、访问组、协议筛选时不发出伪装成已筛选的请求。请求统计仅应用当前接口支持且语义明确的模型/密钥条件；其他维度明确提示，避免未经证明的 ID 映射。
- 使用现有统一客户端、查询清理、主题、CSP、四文件构建；没有更改后端或生成契约。
