| Required property | Review result |
|---|---|

| Compact secrecy | A compact locator is random, owner-scoped and AEAD-protected in a separate table/domain; summaries and stored IDs are reconstructed locally and never forwarded or exposed as raw public output. |
| Resource bounds | Stored payloads use 4096-event/8-MiB bounds; compact generation also has a 2048 output-token ceiling and two-minute total deadline; TTL is fixed at 30 days and begins only after successful completion metadata exists. |
| Canonical semantics | Visible assistant text, ordered Tool calls/results, usage and stop semantics remain replayable; private reasoning stays encrypted and is never invented or projected as visible text. |
