## What to build

操作者主动选择模型和协议后测试调用，结果写入准确的证据范围，配置或授权变化后旧证据失效。

实施编号 CPAR-17；实施批次：A。覆盖用户故事 30, 31, 32, 33, 34, 83, 84；验收场景 T05, T06。

## Acceptance criteria

- [ ] 测试前展示模型、协议、实际目标范围及可能额度消耗，只有主动点击才执行推理。
- [ ] 保存、应用、发现、状态读取、正常续期与解除隔离不会隐式调用此测试。
- [ ] 测试遵守当前 Key／模型权限和目标资格，错误明确，不能借管理入口绕过权限。
- [ ] 结果关联账号的脱敏证据标识、连接、模型、协议、场景、构建／配置和时间；单次成功不扩大到全渠道。
- [ ] 凭据、配置或路径变化后旧证据不再证明当前状态；失败、取消及待确认不得标通过。
- [ ] 受控上游与 EgoLite 验证按钮、真实请求触发次数和证据展示；本票本地测试不发送未经授权的真实 Provider 请求。
- [ ] 记录受影响行为的高层本地验证、必要的 EgoLite 产品验收与审查证据；静态存在、fixture、真实渠道和生产结论分开，结果使用 PASS／FAIL／NOT_RUN／BLOCKED。
- [ ] 保留账号／渠道／权限及数据边界；涉及权威管理契约时单向同步生成客户端，遵守既有前后端归属与跨边界记录；必要 ADR 与相关陈旧测试入口随本切片修正。
- [ ] 在实际 checkout 上复核范围，完成适用 Task／Phase 门槛；本票不自动授权真实账号、收费请求、服务变更或部署，具体外部操作以已明确目标和范围为准。
