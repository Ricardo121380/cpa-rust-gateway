# #22 CPAR-13：账号启停：停止新分配、在途继续

State: OPEN; Updated: 2026-09-29T13:29:05Z

## Parent

[实施规格 #9：CPAR 现有渠道可靠性与管理体验收敛](https://github.com/Ricardo121380/cpa-rust-gateway/issues/9)

## What to build

操作者启停普通或原生账号后能核对是否生效；停用生效后不再分配新请求，已有请求不被主动中断。

实施编号 CPAR-13；实施批次：A。覆盖用户故事 22, 40, 41, 42, 48, 52, 88；验收场景 T03, T07, T12。

## Acceptance criteria

- [ ] 普通配置账号与 native 账号分别演示启停，区分已保存意图、待应用、已生效及失败／待确认。
- [ ] 停用生效后新请求及后续重试不再选择该账号；已有请求自然完成，不因停用动作主动取消。
- [ ] 启用只是允许参与调度，仍遵守授权、连接、权限、额度、容量及精确会话条件。
- [ ] 保留授权、连接、权限和历史；停用账号仍可按既有路径维护授权而不自动启用。
- [ ] 受控长流与并发新请求证明在途／新分配行为；EgoLite 证明操作与生效反馈，不能仅以 lease 对象存在推断整请求完成。
- [ ] 记录受影响行为的高层本地验证、必要的 EgoLite 产品验收与审查证据；静态存在、fixture、真实渠道和生产结论分开，结果使用 PASS／FAIL／NOT_RUN／BLOCKED。
- [ ] 保留账号／渠道／权限及数据边界；涉及权威管理契约时单向同步生成客户端，遵守既有前后端归属与跨边界记录；必要 ADR 与相关陈旧测试入口随本切片修正。
- [ ] 在实际 checkout 上复核范围，完成适用 Task／Phase 门槛；本票不自动授权真实账号、收费请求、服务变更或部署，具体外部操作以已明确目标和范围为准。
