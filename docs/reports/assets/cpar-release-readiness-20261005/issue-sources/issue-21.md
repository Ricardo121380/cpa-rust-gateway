## Acceptance criteria

- [ ] 覆盖现有支持正常续期的普通与原生渠道；API Key 和不支持续期的路径不伪造刷新行为。
- [ ] 明确 grant 撤销／失效停止无效重试，网络、WAF／403、429、5xx 与真实授权失效分开归因。
- [ ] 短暂故障有有限退避与可理解的观察结果；不自动启用停用账号，不改变连接或权限，不发推理测试。
- [ ] 以 revision／当前身份约束晚到结果，不能覆盖更新授权、并发修改或停用意图；失败保留可信旧观察及时间。

- [ ] 记录受影响行为的高层本地验证、必要的 EgoLite 产品验收与审查证据；静态存在、fixture、真实渠道和生产结论分开，结果使用 PASS／FAIL／NOT_RUN／BLOCKED。
- [ ] 保留账号／渠道／权限及数据边界；涉及权威管理契约时单向同步生成客户端，遵守既有前后端归属与跨边界记录；必要 ADR 与相关陈旧测试入口随本切片修正。
