## Acceptance criteria

- [ ] 汇总授权、连接、应用、目录、权限、调度、额度及调用证据，不把一个布尔值或健康分数当作全部事实。
- [ ] 停用显示管理意图；未停用优先调用阻断，其次暂时不可用及关键未知。多个问题有主要原因并可查看其余问题。
- [ ] 未提供额度、读取失败、陈旧观察和可信耗尽分开，未知不填零；局部问题不夸大为整个账号或全部协议失效。
- [ ] 仅配置／续期／目录成功显示调用未验证；最近调用通过必须带具体范围和时间，旧路径证据不能证明新状态。
- [ ] 原生应用失败的全局阻断与单个账号问题分开；历史归属不足标为不完整，诊断不泄露秘密。
- [ ] 读状态不触发续期、调度或推理；HTTP 投影与 EgoLite 状态矩阵一致。
- [ ] 记录受影响行为的高层本地验证、必要的 EgoLite 产品验收与审查证据；静态存在、fixture、真实渠道和生产结论分开，结果使用 PASS／FAIL／NOT_RUN／BLOCKED。
- [ ] 保留账号／渠道／权限及数据边界；涉及权威管理契约时单向同步生成客户端，遵守既有前后端归属与跨边界记录；必要 ADR 与相关陈旧测试入口随本切片修正。
- [ ] 在实际 checkout 上复核范围，完成适用 Task／Phase 门槛；本票不自动授权真实账号、收费请求、服务变更或部署，具体外部操作以已明确目标和范围为准。
