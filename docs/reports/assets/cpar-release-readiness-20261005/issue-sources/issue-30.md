- [ ] 可等价的文本／思考路径通过公共三协议；不可等价能力最早拒绝，响应侧才发现时正确失败。
- [ ] 不通过降低声明、关闭检查或丢思考内容冒充基础目标达标；无法满足的组合保留受阻。
