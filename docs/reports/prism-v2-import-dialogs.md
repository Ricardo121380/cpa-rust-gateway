# V2 账号接入弹窗复核

2026-09-22，基线 `9031e73`。本轮只修改本地正式 Prism 前端，未部署生产。

## 实现

- 渠道名称成为弹窗主标题，去除重复渠道块和已选渠道后仍出现的选渠道说明。
- 凭据来源使用与授权方式一致的分段控件。
- 更换渠道、切换授权/导入、切换粘贴/文件均接入现有 Sheet 未保存保护；点击已经选中的方式不再清空输入。
- 确认放弃后才清除临时凭据；取消确认保留原内容。未变更后端接口、授权流程、秘密存储方式或配置写入逻辑。

## 本轮证据

本地真实网关 `http://127.0.0.1:62992/admin-ui/`，EgoLite Chromium。合成字符串和空 JSON 文件只用于输入/取消验证，未提交账号导入，未启动官方授权或推理。

- 11 个渠道入口 × 390×844 / 1440×900 = 22 个深色布局状态，均未发现弹窗横向溢出或越出屏幕。不是 22 个完整授权用例。
- Grok Console 另检浅色 390×844、1280×720、1440×900。
- 人工图像复核：OpenAI 兼容手机、Kimi Coding 手机、Grok Console 深浅手机、Codex 桌面。其余截图保留，不能算作逐张人工视觉签收。
- Grok Console：重复点击粘贴方式保留内容；更换渠道取消后保留；切文件确认放弃后切换；返回粘贴时输入为空。
- Kimi：导入切官方授权时出现未保存确认；Escape 取消后保留输入；确认放弃后切换；再进入导入时无残留。文件导入切渠道取消后文件仍在，确认放弃后返回渠道选择。
- `AddAccountDialog.test.ts` 5 项现有回归通过；最终 TypeScript 检查与 `cargo build -p gateway --bin gateway` 通过。
- 权威契约同步无变化；SPA 152 操作/CSP/四文件/双构建门禁通过。门禁后只移除了空布局包装节点，最终类型与嵌入构建另通过。
