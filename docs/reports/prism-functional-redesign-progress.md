# Prism 功能重构实施进度

依据：`docs/handoffs/prism-cpamp-functional-redesign.md`。用户于 2026-09-11 授权开始实施。

- 第一批正确性：已修正前端 OAuth 类型为真实 `oauth_json`，新建凭据默认 `bearer`，认证方式改为选择框。Codex OAuth fixture 使用独立凭据，Grok bearer 不提供 Codex 授权操作。类型、契约检查及 20 项凭据／授权／子资源 E2E 通过。首次运行一项旧状态断言失败，更新为独立于认证类型的模拟运行状态后通过。尚待最终真实嵌入式网关验收。
- 第二批账号与提供商接入：进行中。完整受管凭据／端点库存已实现并接到提供商子资源页；未绑定对象立即可见，空提供商也可添加。新增 2 项真实 SQLite/HTTP 回归覆盖 250 个未绑定账号、分页、筛选、禁用记录与同配置 revision 的审计变化；21 项凭据／授权／子资源 E2E、13 项 API 单测和 113 操作权威契约／四文件双构建通过。初次授权／导入、当前配置安全应用尚待完成；无秘密状态修改见后续账号批次。
- 安全编辑底层：新增完整配置 fork 与 schema 23 来源保护；重新加密版本绑定秘密，拒绝 OAuth 轮换及发布／回滚 ABA 后的过期编辑。OAuth 交互会话按配置与账号隔离。3 项控制层、4 项真实 SQLite/HTTP、2 项既有 OAuth HTTP、迁移往返与浏览器编辑回归通过；114 操作契约／四文件双构建和 Clippy 通过。当前只提供设置内“编辑当前配置”，真正运行装配切换尚待实现，未宣称“保存并应用”。
- 账号主页与启停：默认完整凭据列表（一身份一行），未绑定账号可见，服务端搜索，API Key 添加与 Codex 重新授权直达；运行状态保留为子视图，历史深链继续可用。新增无需秘密的状态 PATCH，双 revision 校验并保留密文；真实 SQLite/HTTP 回归及新增 4 项浏览器任务／桌面手机布局检查通过。初始 OAuth、批量导入与操作、资料修改、提供商向导、真实运行切换仍待完成。
- 第三批模型与 Key 工作区：待实施。
- 导航整合：八个一级入口已落实，十四个旧路由通过工作区子页保留；三尺寸、设置及语言共 12 项 E2E 通过。仅合并导航不代表账号接入与配置生效已经完成。
- 第四批请求事实、汇总与网关设置：待实施。

用户指定 Grok 为真实验收渠道。2026-09-11 线上现有 V6 已通过 Grok 4.6 JSON／SSE 各一次、单 Attempt、持久事件和账本关联核对，见 [本次验收](prism-grok-acceptance-20260911.md)。这两条新增请求不代表本地新版账号接入流程已验收。

此记录不表示全方案或生产发布完成。功能重构尚未部署；没有历史数据清理或服务配置变更。

Grok 首次／重新授权验收核对：未通过，管理端尚未接入 Grok Device OAuth 和原生账号持久化。当前 10 项 Grok 底层及 2 项管理授权回归通过仅是合成验证，详见 [授权验收缺口](prism-grok-authorization-acceptance-20260911.md)。没有发生新的真实授权或生产凭据轮换。
