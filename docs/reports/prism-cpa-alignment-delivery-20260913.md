| 工作包 | 本轮结果 |
|---|---|
| 账号 | 移除“读取身份”；身份在授权、导入、更新凭据时取得。统一 10 个真实渠道入口，Kimi 为 API 导入。20 文件/1 MiB 有界预览、逐项结果；普通凭据重复导入保留启停及绑定；批量启停/移除；SSO 更新、原生账号审计和运行应用状态。 |
| 提供商 | 名称、渠道、地址、账号、模型构成接入表单；自动生成内部资源。日常编辑直接保存并应用；移除失去全部启用候选的提供商时，关联模型停用，历史记录保留。 |
| 模型 | 选择真实接口或目录来源，创建公开模型、路由和候选；别名和日常编辑/删除可直接应用；完整路由工作台保留为高级入口。实际 exact ID 不作显示名称替换。 |
| 客户端 | 按模型与有效期签发密钥，自动建立授权组；更新/停用/吊销直接应用。秘密仅签发时显示，关闭后的动画副本也立即清除秘密。 |
| 运行生效 | 完整 serving generation 预构建、精确来源 CAS、进程内切换；保留在途请求及共享并发。原生变更无法应用时暂停新请求，并在设置中提供明确恢复入口。409 不重放写请求。 |
| 目录 | 配置副本继承原始目录时钟；改变/移除账号或接口清理当前范围证据。停用账号的目录保留负面边界，其他未发现目录的账号不能继承其模型权限。已知过期目标待命，硬过期不恢复准入。 |
| 总览/设置 | 资源接入步骤、真实费用及处理状态；安全版本/构建/运行时间/请求准入信息。未观测保留 null；没有虚构的开关或请求成功率。 |

八个一级工作区和全部 14 个旧路由、解锁页及 query 深链保留。配置版本和审计属于高级维护，
普通日常操作自动完成准备、校验与应用；显式选中的已有草稿只保存，不擅自发布其他待修改内容。
视觉沿用已确认的 V6 Liquid Glass。本轮未调用新的 OpenDesign 生成器或外部设计模型。
