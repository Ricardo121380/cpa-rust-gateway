2026-09-13。本轮实施已完成，发布验收仍在执行；本文件会追加实际制品与生产结果。

## 实现

对照范围、固定源码和两套前端的完整结构索引见[差异矩阵](prism-cpa-alignment-matrix-20260912.md)。
CLIProxyAPI 默认提供官方 Management Center 的管理页面，不另算一套独立 SPA。

| 工作包 | 本轮结果 |
|---|---|
| 账号 | 移除“读取身份”；身份在授权、导入、更新凭据时取得。统一 10 个真实渠道入口，Kimi 为 API 导入。20 文件/1 MiB 有界预览、逐项结果；普通凭据重复导入保留启停及绑定；批量启停/移除；SSO 更新、原生账号审计和运行应用状态。 |
| 提供商 | 名称、渠道、地址、账号、模型构成接入表单；自动生成内部资源。日常编辑直接保存并应用；移除失去全部启用候选的提供商时，关联模型停用，历史记录保留。 |
| 模型 | 选择真实接口或目录来源，创建公开模型、路由和候选；别名和日常编辑/删除可直接应用；完整路由工作台保留为高级入口。实际 exact ID 不作显示名称替换。 |
| 客户端 | 按模型与有效期签发密钥，自动建立授权组；更新/停用/吊销直接应用。秘密仅签发时显示，关闭后的动画副本也立即清除秘密。 |
| 运行生效 | 完整 serving generation 预构建、精确来源 CAS、进程内切换；保留在途请求及共享并发。原生变更无法应用时暂停新请求，并在设置中提供明确恢复入口。409 不重放写请求。 |
| 目录 | 配置副本继承原始目录时钟；改变/移除账号或接口清理当前范围证据。停用账号的目录保留负面边界，其他未发现目录的账号不能继承其模型权限。已知过期目标待命，硬过期不恢复准入。 |
| 总览/设置 | 资源接入步骤、真实费用及处理状态；安全版本/构建/运行时间/请求准入信息。未观测保留 null；没有虚构的开关或请求成功率。 |

八个一级工作区和全部 14 个旧路由、解锁页及 query 深链保留。配置版本和审计属于高级维护，
普通日常操作自动完成准备、校验与应用；显式选中的已有草稿只保存，不擅自发布其他待修改内容。
视觉沿用已确认的 V6 Liquid Glass。本轮未调用新的 OpenDesign 生成器或外部设计模型。

- 权威 OpenAPI 129 个操作；通过 sync-contract 同步 DTO/fixtures，保留同源、内存秘密和四文件构建。
- schema 26 仅新增原生账号维护审计；降回 25 前须私有备份新增审计，保留原有账号、管理员、请求和账本。
- 缺少身份的旧 Console SSO 不生成假邮箱，也不因查看页面自动请求 Provider；需要有效资料更新后取得身份。
- 本轮未删除生产账号、请求、账本或测试草稿；未执行真实 Provider 新测试请求。

## 已执行验证

本次输出记录在 `output/prism-cpa-alignment-20260912/`，下面均为本轮执行结果。

- 空安装由 EgoLite 操作真实 gateway：初始化管理员、添加提供商、开放模型、签发密钥；
  同一状态下 loopback TLS Provider 请求成功，持久事件与账本记录产生，首次记录费用 16 微单位、部分置信度。
- 普通账号批量停用后实际模型列表为空；21 文件预检拒绝；重复凭据与坏 JSON 混合导入逐项反馈，原停用状态和连接保留；
  启用后模型恢复。更新凭据后真实 mock 只接受新凭据，后续别名请求成功。
- 模型编辑、添加别名、提供商编辑、接口编辑均无需重启；旧客户端密钥吊销后真实请求 401；
  新签发密钥闭窗时秘密立即从退出动画副本清除。移除唯一提供商后关联模型停用，再删除模型成功。
- Rust：本轮全工作区测试与全特性 Clippy 通过；原完整脚本在 crate boundary 漏登记 C1 的 arc-swap 时停止，
  已修复该登记并逐项补完边界、文档链接、契约引用、秘密扫描、deny 和 audit，未伪称原脚本退出为零。
  后续目录隔离变更重新通过实际运行测试 96 项、管理接口 15 项及 gateway 全目标/全特性 Clippy。
- 新增针对性回归覆盖 schema 26 升降级、原生状态/替换/删除/审计 CAS、失配身份拒绝、重复导入、
  运行暂停恢复、在途容量、目录硬过期、跨账号目录隔离、当前版本目录清理。
- 前端 280 项单测、TypeScript、129 操作契约/嵌入门禁与四资产重复构建通过；
  Playwright 规格已维护，本地实际浏览器验收按用户要求仅使用 EgoLite。
