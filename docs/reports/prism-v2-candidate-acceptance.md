# V2 候选编辑与删除验收

2026-09-22，基线 `542d2c2`。仅使用 EgoLite 和 `127.0.0.1:62992` 隔离真实 gateway；未部署生产、未调用真实 Provider。

## 实际操作

- 从当前活动配置复制 `V2 candidate acceptance` 草稿。编辑 `Exact/Model-v2` 的候选权重，保存后重新进入编辑确认值为 4。
- 首次自动化数字输入误写为 24，读回发现后纠正为 4；没有把首次输入当作通过。后续滚动时聚焦的数字控件也发生过浏览器步进，退出时放弃了该次未保存输入。
- 确认删除该候选，服务端重读由 2 条变为 1 条，保留 `Model-Second`；对应路由返回 `route_missing_active_candidate`。该失败符合删除最后启用来源后的拓扑要求。
- 草稿未发布。重启本地 gateway 后仍读到上述草稿及唯一剩余候选；当前已发布配置仍保留原来的两条候选。

## 本轮修正

- 编辑表单不再把不可编辑的随机候选 ID 当作主要字段；使用现有“关联信息”组件显示模型身份，保留复制内部引用。新建时的自定义候选标识输入仍保留。
- 协议转换选项显示现有语义说明，提交的枚举值保持不变；原始模型 ID 不改写。
- 桌面优先级与权重并排，手机纵排。
- 真实截图发现桌面 sticky 保存栏横跨调度字段。候选表单改为内容末尾的静态操作栏，不影响其他编辑器。
