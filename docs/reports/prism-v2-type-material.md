## 仍然存在的设计差异

本轮完成字体与共享材质统一、首页骨架细化、账号选择入口；**不将其宣称为全站完整复刻**。原型与产品数据密度不同；提供商/模型/密钥的复杂编辑、目录分页、批次结果和错误/空态还需逐页同尺寸对照，而不能仅凭页面存在或上述布局矩阵宣布完成。三面 chrome 的 GlassSurface/PrismLens、真实操作保护和手机可触控布局继续保留。原型中的演示管理员、团队角色、虚构指标不接入产品。
