## 与原型的必要差异及验收边界

- 原型的演示身份、套餐、费用分摊和固定模型不进入正式前端。合成本地 API 账号缺少身份时仍明确显示未知。
- 用量页保留真实六类 Token 聚合；原型按预设比例生成的“费用来源”不照搬。真实计价与置信度通过费用/账本入口核对，不伪造费用分配表。
- 实际价格批量编辑、分页和未知结果协调器比原型的说明弹窗更完整，沿用正式工作区承载；配置差异显示后端返回的字段变化，不编造前后值。
- 本轮完成计划列出的剩余结构实施与上述本地检查；不宣称像素级完全一致或替代用户的视觉判断。
- 真实官方授权的中间验证码/回调/远端完成状态未在本轮重新触发；这些状态的结构已实现，业务回归与首次入口分别记录，不冒充真实授权成功。
- 不涉及生产上线、DNS/Caddy、Autoreg、数据清理或全渠道真实推理验收。
