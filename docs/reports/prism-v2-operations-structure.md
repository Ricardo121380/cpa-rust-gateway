# V2 密钥、用量与设置结构

2026-09-22，基线 e3ca27f。本批本地开发，未部署生产。

## 实现

- 密钥详情采用身份/状态、使用与有效期、明确允许模型三个分区；直接复用版本一致的权限摘要，完整模型列表保留 exact ID 与已关闭标记。编辑入口固定在抽屉底部，秘密不可回读。
- 设置中连接与会话改为统一横向行，保留到期时间、改密与退出行为。辅助偏好仍由原 store 控制。
- 用量时间控件移至标题区，摘要改为三列；手机六类 Token 转为带标签与独立置信度的双列卡片，保留汇总、未知值与下界标记。
- 精确时间深链明确展示当前范围，不再误选预设时间按钮；选择预设后按原流程清除精确边界。未更改查询或聚合统计语义。
