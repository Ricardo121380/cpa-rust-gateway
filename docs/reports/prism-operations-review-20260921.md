# 请求日志与用量费用核对 — 2026-09-21

## 结论与修改

基于上一批模型开放与受限密钥闭环留下的真实本地 gateway 数据，核对请求日志、详情、账本与用量页面。发现请求日志包含 6 个外部请求，用量页面仅包含 3 个收到用量的请求，原先都标为“请求数”容易误解。本批将用量摘要明确为“有用量记录的请求”，简化观测口径说明，并统一提供商、接口和 API 密钥中文标签。没有修改统计计算、接口契约或权限。

本批未部署；不代表全部栏目、全站视觉或生产浏览器验收完成。

## 数据与真实应用证据

使用上一批隔离合成状态的 SQLite 备份，运行重新构建的真实嵌入 gateway（管理端 loopback 55380、数据端 55381），EgoLite 操作正式应用。未使用前端 fixture 替代接口，未调用真实 Provider 推理；本批只读取前次 loopback mock 请求的持久记录。

| 检查 | 实际结果 |
|---|---|
| 全部请求 | 6 条：成功 3、失败 2、取消 1；成功率 50% |
| 失败筛选 | 2 条，包括上游 503 与流式截断；未误计为成功 |
| 取消筛选 | 1 条，没有账本记录 |
| Model-Second 请求筛选 | 1 条成功，1 次尝试；总耗时与首内容延迟均为 59ms |
| 未计价详情和账本 | 显示“— / 无价格”，未计价 1 条，已知费用为空；未用零费用替代未知 |
| 全量用量 | 3 个有用量记录的请求，输入 30、输出 9；其他四类 Token 未观测，保留未知 |
| Model-Second 用量筛选 | 1 个有用量记录的请求，输入 10、输出 3 |
| 最终嵌入应用 | 重建并重启后重新登录、重读和筛选，新的中文标签与口径生效 |

数据来源与原始闭环证据见 [上一批报告](prism-model-key-chain-20260921.md)。请求终态、账本和用量是不同记录范围，本批没有为缺失用量或时延补造数值。
