# Prism Liquid V2：页面结构复刻

2026-09-22；基线 `ce56326`。这是用户指出第一版复刻不足后的第二轮实现。以存档 `docs/design/chatgpt-prism-liquid-v2/CPAR-Prism-Liquid-v2.html` 为视觉参考，沿用正式 React 页面和真实管理接口。本轮没有部署生产。

## 实际修改

| 工作区 | 本轮变化 |
|---|---|
| 共享外壳 | 品牌比例/蓝色、内容边距、较轻顶栏阴影；下划线工作区页签位于主页面标题之后 |
| 总览 | 时间选择与刷新合入主标题；移除重复“请求概览”标题，四指标紧接标题；收紧趋势图高度 |
| 账号 | 原来分离的大卡片变成连续数据面板；保留渠道分组和 Grok 子类；身份头像、紧凑分组标题；渠道筛选合入工具栏 |
| 提供商 | 紧凑来源列表＋右侧接入说明；选择后右侧切换为真实接口/账号维护；次要编辑放进“更多”；协议、主机与配置状态仍可见 |
| 模型与目录 | 标题/说明、下划线页签、原始模型 ID 和真实连接保持一致；不填造“运行可用” |
| API 密钥 | 密钥列表优先，高级访问组后移；秘密不可回读的呈现与列表计数；签发、编辑、吊销不变 |
| 请求 | 标题层级、下划线页签；时间/模型/结果为直接筛选，渠道/账号/密钥为可展开筛选；已有条件自动展开；处理状态移至内容后 |
| 用量/价格 | 页签移到标题下；按需展开筛选，已有条件保持可见；KPI 层级调整；处理状态与口径说明后移；保留六类 token 与置信度 |
| 设置 | 将分离的大卡片重组为单面板横向设置行，辅助偏好使用可键盘操作的开关；会话与真实系统信息随后显示 |

## 与原型保留的差异

- 原型的健康数、模型可用性、额度、费用与数据条数都是演示；正式页面只用服务端真实字段，不为外形一致填造这些值。
- 真实草稿提示、冲突、分页、错误、未观测和高级路由/计费维护保留，因此页面高度和操作数可能多于原型。
- 原型简单提供商/价格表单不替换真实复杂维护工作区。设置保留“跟随系统”、语言和已有维护路由，没有移植离线材质实验室。
- 本轮是结构与视觉进一步对齐，不宣称像素级完全一致或 V2A–V2E 所有业务验收完结。C2C 上一轮的 APPROVED_FOR_LOCAL_PREVIEW 不作为此次新增改动的独立复审。
