- 全站主题／窄屏／状态清单、完整既有数据升级／回退、真实渠道、远端 CI、新候选制品、部署和生产不以本批页面 PASS 代替。
- 合成 AccessGroup 准备重用了唯一 name/id 时返回 500；保留原失败，合法输入改为运行专用命名。重复资源错误分类列后续，不扩大本批改动。
- 首次强制改密指针暂态拦截未稳定复现；第二次同源指针操作通过，保留两份结果，不声明布局缺陷已修复。
- 旧 Grok API 非规范组件不自动迁移或启用；必要时由操作者核对固定规范组件与已有关联。
