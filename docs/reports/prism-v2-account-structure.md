## 已实现

- 账号页将主操作、授权状态筛选、搜索与批量工具分层。保留渠道分类、Grok 子分类、套餐筛选、排序、分页和真实操作入口；授权状态不会冒充调度状态。
- 普通与原生账号共用身份头部（身份、渠道、接入方式和状态），详情以概览/额度/配置/模型/诊断组织。概览减少重复标题；原生账号概览直接呈现真实关联协议和地址，读取失败/无连接分别表达。
- 模型按 V2 将原始 ID 与提供商来源放入同一单元格，保留所有来源、协议、开放状态与维护入口。手机使用整行卡片；修复新桌面列宽导致手机模型名过早换行的问题。
- 提供商列表收敛为渠道、去重协议、配置模型数和入口，地址与连接维护保留在右侧工作区。
- 未新增 API、依赖或模拟业务；原有写入协调器、会话所有权、冲突处理、关闭保护不变。
- 请求详情按 V2 分为模型/终态、时间与计价、Token 用量、尝试时间线和请求标识。补改后类型检查、6 项请求回归、152 操作四文件双构建及 gateway 编译通过；真实合成请求的三个尺寸详情截图无横向溢出，保留 56 ms、1 次尝试和无价格等实际数据。未发起新推理。
