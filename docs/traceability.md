# Public traceability index

Public behavior is traced through the following stable artifacts:

- architecture decisions in [`adr/`](adr/README.md);
- executable behavior contracts in [`contracts/`](contracts/README.md);
- protocol and provider fixtures under `tests/` and individual crate test directories;
- quality gates documented in [`quality-gates.md`](quality-gates.md).

Operator-specific delivery receipts and infrastructure traceability are intentionally kept in
the private development archive.
